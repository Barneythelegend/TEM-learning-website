為什麼有些量測是影像、有些是光譜？

影像：記錄空間位置或掃描位置對應的訊號強弱。繞射圖：記錄不同散射角的電子強度。光譜：把 X 光能量或電子能量損失分開，分析能量分布。

物理訊號不等於直接結論

明場暗區未必代表「原子序高」；高角環形暗場亮區也不保證是某個指定元素。相鑑定、元素確認與界面分析通常需要影像、繞射和光譜交叉驗證。

測量位置的重要差異：物鏡光闌選擇哪些電子束參與成像，不是電子偵測器；選區光闌決定繞射訊號來自哪個樣品區域。而影像的快速傅立葉轉換（FFT）是數學處理，不是另一組偵測器。以上位置為典型配置，實際儀器可能不同。

一束電子如何變成繞射圖和明暗場影像？

從同一個超薄晶體樣品出發，按照「散射方向 → 光闌選束 → 透鏡投影 → 相機讀取」的順序理解。這是常規穿透式電子顯微鏡（Conventional TEM）的示意；下方的掃描穿透式電子顯微鏡（STEM）使用不同的成像方式。 課堂 slide 45、58–64、82、87–98、105–106

影像模式與繞射模式的差別

繞射圖是把「電子往哪個方向走」畫出來；影像是把「樣品哪個位置亮或暗」畫出來。

同一批電子，為什麼會變成 BF 或 DF？

不是電子種類不同，而是物鏡光闌像「方向選擇門」，你選哪一道束，最後相機就用那一道束來組成影像。

01

電子不是穿過「人造狹縫」才繞射

電子具有波動性。晶體內原子和其電位週期性排列，電子波受到散射後互相干涉：有些方向增強，有些方向抵消，因此產生不同出射方向的繞射束。可以想像許多排列整齊的噴泉同時產生水波，水波重疊後在某些方向特別強。布拉格定律 2d sinθ = nλ 描述這些方向的條件；它不是說電子真的像小球撞到鏡子再反彈。

02

同一束入射電子，為什麼可以出現好幾道束？

晶體有不同方向與間距的晶面組；同一入射電子波可被分成近乎直行的直射波分量（000），以及沿不同繞射方向傳播的波分量（g₁、g₂ …）。每一道束的強弱取決於晶體結構、取向、厚度與繞射條件；不同方向不是隨機產生的。

03

物鏡後焦平面：按「出射方向」把電子分開

物鏡（Objective Lens）把以不同角度傳播的電子分開聚焦到物鏡後焦平面（Back Focal Plane）：直射束在中心，各繞射束落在其他位置。此處每個斑點的位置反映散射方向／空間頻率，亮度反映那個方向的電子強度。繞射斑點不是樣品某一顆原子的照片。

04

物鏡光闌像「方向選擇門」，不是偵測器

物鏡光闌（Objective Aperture）是一片有孔的實體擋板，放在後焦平面附近。孔對準中心：讓直射束通過，形成明場成像（Bright-Field, BF）。孔對準某個繞射點：讓那道繞射束通過，形成暗場成像（Dark-Field, DF）。沒有被選中的束被擋掉；光闌只篩選電子，不負責量測亮度。

05

為什麼暗場不會只拍到「一個繞射點」？

因為物鏡同時具有像平面（Image Plane）。選完某個電子束後，物鏡與後續透鏡仍會把樣品各處的訊號重建到原來各自對應的位置，成為明場／暗場影像。將像平面投影到相機，得到位置地圖；將後焦平面投影到相機，得到方向／繞射圖。兩者的「相機」可以是同一個底部相機，差別主要在透鏡選擇投影哪個平面。

06

相機實際接收什麼？

相機接收的是電子訊號。傳統方式可利用閃爍體把電子轉成光，再由相機感測器轉成電訊號；直接電子偵測器則直接記錄入射電子的訊號。每個畫素得到一段曝光期間的電子訊號強度，再顯示為明暗。繞射模式的畫素座標代表束的方向；成像模式的畫素座標對應樣品的位置。這與旁邊的 EDS 偵測器接收「特徵 X 光」完全不同。

互動實驗｜相同晶體與入射束，切換「收哪一道電子」

兩個晶粒具有不同晶體取向：晶粒 A 較容易把電子繞射往 g₁，晶粒 B 較容易往 g₂。操作下方按鈕，觀察後焦平面的選束位置與最後相機畫面。

實空間與倒空間：一張是「位置地圖」，一張是「間距與方向地圖」

實空間問「A 晶粒在樣品左邊還是右邊？」；倒空間問「晶體有哪些週期性間距、對應哪些散射方向？」倒空間不是另一個可進入的物理空間，而是用空間頻率描述結構。對一組晶面，常用 g = 1/d（若使用角波數慣例則含 2π），其中 d 是晶面間距。

實空間：條紋之間的距離
倒空間：繞射點離中心的距離

間距越小，倒空間點離中心越遠。本圖使用相同尺度及固定相機長度的概念模型。

FFT 是什麼？為什麼不等於直接量測的繞射圖？

快速傅立葉轉換（Fast Fourier Transform, FFT）是對「已拍到的影像亮度」做數學運算，找出條紋等空間週期。選區電子繞射（Selected-Area Electron Diffraction, SAED）則是把真實電子束依散射方向投影到相機所得到的繞射圖。兩者可能有相似點位，但影像受離焦、相位傳遞、取樣及雜訊影響，因此不能直接當成完全相同的訊號。

一句話記住：後焦平面看方向；像平面看位置。物鏡光闌選哪一道束；底部相機量電子訊號的強度分布。傳統 TEM 的 BF／DF 是利用選束後的透鏡成像；STEM 的 BF／ADF 通常是探針逐點掃描＋角度選擇偵測器。
繼續：選區電子繞射模擬器繼續：明場與暗場成像
Q：繞射圖中一個點越亮，表示那種元素越多嗎？

不能這樣直接推論。斑點強度受結構因子、晶體厚度、取向、動力學多重散射、曝光及探測條件影響；要確認元素成分，應搭配能量色散 X 光光譜（EDS）或電子能量損失光譜（EELS）。

Q：暗場是不是只把一個斑點放大成影像？

不是。物鏡光闌在後焦平面選擇一道繞射束後，透鏡仍把各樣品位置的選束強度投影到像平面，形成有位置分布的影像；符合該繞射條件的晶粒會比較亮。

Q：暗場究竟是擋掉什麼？是感測器故意不收嗎？

在常規 TEM 暗場成像中，主要由物鏡光闌物理阻擋直射束及不需要的其他繞射束。真正的相機在後方記錄被允許參與成像的電子。部分模式也可以傾斜入射電子束，使所選繞射束沿光軸通過光闌。

Q：那 STEM 也是用同一套物鏡光闌產生 BF／DF 嗎？

不要混為一談。常規 TEM 以近平行電子束照亮一片區域，透鏡投影成像；STEM 以會聚電子探針逐點掃描，用樣品下方不同角度範圍的電子偵測器，在每個掃描位置記錄強度，再將數值排列成影像。

00 TECHNICAL TERMS

核心技術名詞速覽

本網站首次介紹技術時，使用中文名稱、英文全名與縮寫。下列名詞可用於快速查閱後續章節中的成像、繞射與光譜機制。

明場成像（Bright-Field, BF）

主要選擇直射電子形成影像；把電子大量繞射出去的地方，可能看起來較暗。

暗場成像（Dark-Field, DF）

刻意選擇某一道繞射電子束；符合該繞射條件的晶粒可能較亮。

選區電子繞射（Selected-Area Electron Diffraction, SAED）

直接收集指定樣品區域的電子繞射圖，從斑點或環推論晶體排列。

高解析穿透式電子顯微術（High-Resolution TEM, HRTEM）

利用電子波干涉呈現晶格條紋等細節；亮點不一定就是原子位置。離焦與球面像差會共同影響相位對比。

快速傅立葉轉換（Fast Fourier Transform, FFT）

把已拍好的影像轉成空間頻率圖，找出條紋間距與方向；不是另一台儀器。

掃描式穿透電子顯微術（Scanning TEM, STEM）

把電子束聚焦成細探針，逐點掃描薄片，記錄不同角度或光譜訊號。

高角度環形暗場（High-Angle Annular Dark-Field, HAADF）

STEM 的一種高角度電子偵測方式，常有較明顯的原子序對比。

能量色散 X 光光譜（Energy-Dispersive X-ray Spectroscopy, EDS）

量元素放出的特徵 X 光，協助辨識元素與其分布。

電子能量損失光譜（Electron Energy-Loss Spectroscopy, EELS）

量穿過樣品的電子損失多少能量，研究元素及部分化學鍵結資訊。

成像訊號概要：穿透薄片 → 電子部分直走、部分繞射 → 選直射束做明場（BF），選繞射束做暗場（DF）；要看晶格條紋可用高解析 TEM（HRTEM），再用快速傅立葉轉換（FFT）檢查週期性。

TEM 到底怎麼運作？

TEM 是把高能電子經電磁透鏡導向超薄樣品，再利用透射電子形成像或繞射圖樣；中間最核心的兩個平面是 Back Focal Plane（倒空間）與 Image Plane（實空間）。slide 5–14、31–46、79–87

200 kV 是什麼概念？

電子不是可見光，但具有 de Broglie 物質波。加速電壓越大，波長越短；然而真正解析度仍受球面像差、色差、震動、樣品厚度與訊噪比限制。

概念示意：選擇過小聚焦角可能受繞射限制，過大角又可能增加像差。非實際儀器曲線。
老師可能問：TEM 為什麼要真空？

讓電子在顯微鏡內不被空氣分子大量散射，也減少電子槍污染與不穩定；不同區段對真空程度要求不同。不是因為「電子一定無法在空氣中移動」，而是希望保有高品質可控電子束。

老師可能問：Condenser Lens 和 Objective Lens 差在哪？

Condenser 主要設定入射照明的束流與會聚角；Objective Lens 在樣品下方負責初步成像／繞射空間形成，是 TEM 解析度、對比與像差的重要來源。

老師可能問：TEM 跟 STEM 有什麼差別？

傳統 TEM 通常用較寬的近似平行束照亮區域，由透鏡投影影像；STEM 則聚焦成很小的探針逐點掃描，記錄各角度或光譜訊號形成影像。兩者常整合在同一台 (S)TEM。

02SAMPLE PREPARATION

為什麼 TEM 試片必須薄？

因為電子需要「穿過」樣品，太厚會有大量非彈性／多重散射，降低可解析度及繞射／光譜的可解釋性。課堂講義以 <100 nm 作為常見薄片目標，不代表所有材料或量測方式都有同一固定厚度門檻。slide 15–30

試片為什麼要薄？

TEM 不是越厚越好。太厚會增加多重散射，讓影像和繞射都更難判讀。

先用圖抓住：倒空間與繞射圖樣到底在看什麼？

實空間 vs 倒空間

d 越小，倒空間點越遠；所以倒空間是在記錄週期有多密。

單晶、多晶、非晶質

多晶有很多不同取向，所以同一半徑的繞射強度沿圓周鋪開；非晶質缺少長程有序，因此變成模糊暈環。

繞射圖量到什麼？

繞射圖是「不同出射方向上的電子強度分布」，不是原子照片。

實空間（原子距離）與倒空間（空間頻率）

自己改變晶面間距，觀察實空間原子點距與倒空間繞射點距離如何反向變化。這個滑桿會和前面成像章節同步。

繞射圖是選定區軸 [uvw] 的倒空間截面。立方晶系的 zone-axis condition：

hu + kv + lw = 0

同一個 pattern 的不同點必須同時滿足區軸與消光規則。以 Si [110] 為例，(1−11) 可能允許，(002) 在運動學近似下禁制。

04IMAGE FORMATION · APERTURE

明場（Bright-Field, BF）與暗場（Dark-Field, DF）到底怎麼拍？

這兩種模式都是同一台 TEM 讓電子穿過晶體後，使用物鏡光闌選取不同方向的束，再將各位置訊號投影至底部相機。建議先看「一束電子如何變成影像？」，觀察同一樣品在「繞射圖／明場／暗場」之間如何切換。物鏡光闌（Objective Aperture）在物鏡後焦平面附近選電子束；選區光闌（Selected-Area Aperture）則限制做選區電子繞射（SAED）的樣品範圍。亮暗也會受厚度、晶向與散射影響。slide 87–98

OBJECTIVE APERTURE · BF / DF

明場與暗場：同一份繞射訊號，為什麼拍出兩種影像？

想像你提供的成像示意圖：電子穿過晶體後，物鏡把不同出射方向的電子分到後焦平面。光闌開孔對準哪一個繞射點，就決定使用哪一道電子束參與實空間成像。

明場成像 · Bright-Field TEM（BF-TEM）

物鏡光闌對準直射束 000

光闌主要放行中央直射束。晶粒若把較多電子繞射到其他方向，留在 000 的電子變少，因此該晶粒往往比較暗。

暗場成像 · Dark-Field TEM（DF-TEM）

光闌選擇某一道繞射束 g

光闌選定離開中心的繞射束 g。特定晶粒若符合這道束的繞射條件，送進光闌的電子較多，就在原來的樣品位置呈現亮色。

你看到的 000、g 點是在「倒空間」後焦平面上分開的繞射束。
光闌的角色決定哪一道電子束參與成像；光闌本身不負責偵測。
相機拍出的 BF／DF仍是「實空間」影像，因為後續透鏡把所選束重組成像。

注意：這是依據你提供的成像原理示意概念重新繪製的教學圖，不是光學電子軌跡的精確追跡。示意把兩種光闌位置畫在同一平面比較；真實儀器是調整光闌相對繞射束的位置，並非同時存在兩個選束孔洞。明場／暗場對比亦受樣品厚度、晶向與多重散射影響。

明場（BF）示意

如果某個區域把很多電子散射走，能通過中央孔洞的直射束就變少，那個區域在 BF 影像就會較暗。

暗場（DF）示意

只有符合該繞射條件的晶粒或區域會亮起來，因此暗場很適合做相選擇與晶粒辨識。

①電子穿過薄片

一些電子近乎直走（直射束）；另一些電子受到晶體繞射，偏到不同方向（繞射束）。

②物鏡光闌選束

光闌像「有洞的擋板」，決定哪些電子能通過並形成影像。

③比較明暗

選直射束是明場（BF）；選特定繞射束是暗場（DF）。同一晶粒在兩種影像中可能亮暗反轉。

實際操作：選明場或暗場，觀察兩塊晶粒

這是一個「兩個晶粒不同布拉格條件」的概念模擬；亮度不是多重散射方程的數值解。

05HRTEM · FFT · DEFECTS

高解析 TEM（HRTEM）拍到晶格條紋，代表什麼？

06SCANNING TEM

掃描穿透 TEM（STEM）與高角度環形暗場（HAADF）：重元素一定亮？

掃描式穿透電子顯微術（Scanning TEM，STEM）使用會聚細電子探針逐點掃描；不同環形偵測器收取不同散射角。高角度環形暗場（High-Angle Annular Dark-Field，HAADF） 在很多條件下具較明顯的 Z contrast，但厚度、晶向、channeling、偵測角與劑量同樣重要。slide 109–116

STEM：偵測器形狀直接決定你收哪個角度

不是「換儀器」才改成 ADF／HAADF，而是同一個 STEM 探針，改變收集角度與偵測器形狀。

量到不同散射角，有什麼意義？

小角度中角度高角度
  • 小角度／中央束：較接近明場；對相位、厚度、繞射條件敏感。
  • 中角度 ADF：常提供質量–厚度對比，影像直觀度比 BF 高。
  • 高角度 HAADF：較常呈現 Z-contrast；重元素通常更亮，但厚度、晶向與 channeling 仍重要。

所以「不同散射角」的意義，就是你在強調不同的材料資訊：缺陷？厚度？還是重元素分布？

07ANALYTICAL ELECTRON MICROSCOPY

如何測元素與化學狀態？特徵 X 光（EDS）與電子能量損失（EELS）

能量色散 X 光光譜（Energy-Dispersive X-ray Spectroscopy，EDS）量的是樣品放出的特徵 X 光；電子能量損失光譜（Electron Energy-Loss Spectroscopy，EELS）量的是穿過樣品後電子失去了多少能量。兩者互補，不是誰比較「高級」。slide 117–130

EDS：測到的是特徵 X-ray

不同元素的能階差不同，所以放出的 X-ray 能量具有元素指紋。

EELS：測到的是穿透電子損失了多少能量

EELS 看的是電子本身失去了多少能量，因此可分析化學態、鍵結與低 Z 元素。

光譜形狀與訊號來源理想化曲線示意
示意光譜，峰位置只供概念辨識，非真正樣品數據。

EDS：特徵 X-ray

入射高能電子移走內殼層電子，外層電子填補空穴時釋放元素特徵 X 光。EDS 可做點分析、線掃描、元素 mapping，但譜峰重疊、吸收、厚度、螢光與偵測器幾何都會影響定量。

氧化態或鍵結改變？ELNES / EELS 邊緣精細結構
幾奈米的局部析出物？HAADF + EDS／EELS + diffraction
不能從「EDS 沒測到」直接判定元素不存在。低濃度、譜峰重疊、樣品厚度、偵測靈敏度或束損傷都可能造成漏判。

兩個容易混淆的機制

EDS：電子打掉內殼層電子 → 其他電子躍遷填空 → X-ray photon 被偵測。

EELS：電子束穿過薄片時發生非彈性散射 → 量測出射電子失去的能量 → 零損峰、電漿子、核心損失邊與近邊精細結構。

為什麼薄片仍需要好好選？

厚片會增加多重非彈性散射，讓 EELS 低損峰／core-loss 更難解析；對 EDS 來說，厚度與吸收也影響 X 光定量。TEM 空間解析度很高，但分析體積、投影與訊號統計仍需小心。

真正的材料分析：從一張圖建立證據鏈

PBL 最強的回答不是「它是什麼」，而是「我的初步判斷是什麼、還缺什麼驗證、下一張圖該怎麼拍」。這三個案例刻意涵蓋半導體元件、晶相辨識與敏感薄膜。

案例 A先進封裝／薄膜界面

跨材料界面出現 4 nm 暗層

BF-TEM 顯示暗層，能否斷定界面發生了擴散？

展開專業分析

不行。BF 暗帶可能來自質量厚度、繞射條件、投影重疊或局部損傷。先用不同傾角／HAADF 查看對比是否維持，再用 STEM-EDS／EELS 做化學剖面，必要時比對 FIB 製樣背景與 HRTEM 晶格。

案例 B未知晶相

出現不符合已知晶格的斑點

看到禁制點就代表發現新相嗎？

展開專業分析

先排除多重散射、雙晶、重疊晶粒及索引錯誤。檢查 zone axis、斑點夾角與消光，改變 tilt/厚度，取得至少三個 SADP，再以 EDS 候選元素與晶體資料庫交叉比對。Si(002) 就是經典追問。
